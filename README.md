# Rapid Schools — Unified Educational Portal

Official portal for **Rapid Schools**, encompassing:
- **Rapid Dreamz**: Nurturing Early Childhood Education (Play Group, Nursery, LKG, UKG)
- **Rapid Shakuntlayan**: Comprehensive Senior Secondary Education (Class 1 to 12, CBSE affiliated)

## 💎 Design & Aesthetics

- **Academic Sapphire Palette**: Deep Navy (`#020617`, `#0F172A`, `#1E293B`), Warm Amber & Champagne Gold (`#D97706`, `#F59E0B`, `#FBBF24`), Clean Slate White (`#F8FAFC`, `#FFFFFF`), and Teal/Emerald accents.
- **Editorial Typography**: 
  - Headings: *Cormorant Garamond* (Scholarly serif)
  - Structural Badges & Metrics: *Outfit* (Geometric sans)
  - Body & UI: *Plus Jakarta Sans* (Legible modern sans)
- **Full Responsiveness**: Mobile drawer, bottom quick-contact bar, touch-friendly navigation, and WCAG 2.2 AA compliant contrast.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 8 + Tailwind CSS v4
- **Routing**: React Router v7 with GitHub Pages SPA routing support
- **Icons**: Lucide React
- **CI/CD**: GitHub Actions automated build & deployment to GitHub Pages

---

## 🚀 Local Development

1. **Clone repository**:
   ```bash
   git clone https://github.com/killind0d0/rapid-schools.git
   cd rapid-schools
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   ```
